# 異業合作探索器

老闆的接案學院（CEO Brian）課程內部工具。

幫接案者用「顧問式合作」邏輯，產出客製化的異業合作策略地圖，讓案源主動進來，不靠 cold call。

## 功能

- 輸入專業、客群、區域、報價，AI 產出客戶生態圈分析（上游/平行/下游）
- 5 個最值得開發的合作對象，附開場話術
- 每個對象可深挖：
  - **★ 去哪找這類人**（公開合法管道：公會、產業活動、官網、實體拜訪）
  - 三封不同風格的開場信
  - 對方可能的拒絕理由 + Brian 風格回應
  - 三階段長期合作演進路徑
- 自動存檔，支援多份地圖管理
- 列印 / 存 PDF

## 使用方式

直接打開網址即可。第一次使用需要設定 Anthropic API Key（一次性，5 分鐘）。

## 給學員的設定步驟

1. 到 [console.anthropic.com](https://console.anthropic.com) 註冊帳號
2. 左側選單 → **API Keys** → Create Key
3. 複製產生的 Key（以 `sk-ant-` 開頭）
4. 在 Billing 充值最低 5 美金
5. 打開工具，貼上 Key，開始使用

## 費用估算

- 每張地圖約 NT$1
- 每次深挖約 NT$0.5-1
- 5 美金（NT$160）可以用幾百次

API Key 只存在學員自己的瀏覽器，不會傳到任何第三方伺服器。

## 合規聲明

本工具產出的「找人管道」僅包含公開合法的接觸管道（公會、協會、產業活動、公司官網的公開資訊、實體門市拜訪等），不會輸出個人手機、私人 email，也不會建議任何違反個資法的行為。
