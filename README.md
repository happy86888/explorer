# Brian's Toolkit

老闆的接案學院（CEO Brian）學員專屬工具集。

從找方向、找客戶、寫提案、談價格、簽約、判斷案件、處理客戶溝通、改善作品集、催收尾款、到設計長期合作——10 個工具涵蓋接案者完整的職涯旅程。

## 目前可用的 10 個工具

### 00 我是新手，想接案（Where to Start）
完全沒接過案？告訴我你會什麼，AI 從 30+ 平台中挑出最適合你的入口、給你 7 天行動清單、6 堂新手必修觀念課，還包含「你還沒會這個技能該怎麼學」的學習路徑。

### 01 異業合作探索器（The Allied Map）
告訴它你的專業與目標客群，AI 幫你畫出客戶生態圈、5 個高價值合作對象、開場話術、找人管道。

### 02 高價報價產生器（The Price Architect）
輸入案件條件，AI 用「商業價值」思維產出 3 段式報價、開場話術、預想拒絕回應。支援「低價買門票」到「提高 2 倍」的多種策略。

### 03 客戶異議拆解器（The Objection Decoder）
把客戶的拒絕原話貼進來，AI 拆解他真正擔心什麼，給你 3 種回應劇本、跟進計畫、漂亮放生策略。

### 04 合約陷阱檢查器（The Contract Sentinel）
把合約貼進來，AI 用接案者角度找出地雷條款、缺漏條款、給整體風險評分，並產出修改建議信。

### 05 案件健診器（The Brief Doctor）
客戶剛傳來需求？先健診！AI 給案件評級（A/B/C/D）、雷案訊號、客戶心理側寫、該不該接、第一封回覆建議。

### 06 客戶溝通翻譯機（Client Decoder）
「再幫我修一下整體感覺」「我朋友覺得不太對」這些話到底什麼意思？AI 翻譯客戶潛台詞，給你 3 個專業回覆版本。

### 07 作品集診斷器（Portfolio MRI）
從客戶視角給你的作品集 5 面向評分（第一印象、案例敘事、信任元素、客群匹配、行動引導），告訴你該砍掉什麼、補上什麼，附 30 天改造計畫。

### 08 尾款催收器（The Collector）
描述你被客戶拖款的狀況，AI 設計 3 階段催收訊息（友善 → 公事 → 最後通牒）、評估法律途徑可行性、給下次預防清單。

### 09 月顧問費設計器（The Retainer Builder）
單次案結束想轉長期？AI 設計月費 / 季費 / 年費結構，告訴你每月該交付什麼、怎麼提案、怎麼讓客戶說好。
