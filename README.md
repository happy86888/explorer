# 異業合作探索器 v2

老闆的接案學院（CEO Brian）課程內部工具。

幫接案者用「顧問式合作」邏輯，產出客製化的異業合作策略地圖。從一張地圖開始，可以一直深挖、對話、產出可用內容，直到真的接到案。

## v2 新功能

**🎓 教練筆記（D）**
- 每張地圖最上方有 Brian 的「策略註解」
- 每個合作對象的「為何合作」下方有「教練觀念提醒」

**💬 跟 Brian 聊聊（B）**
- 每個合作對象都可以開啟對話面板，問任何卡關的問題
- AI 完全記得你的背景、合作對象的脈絡
- 對話自動存檔

**📦 整套接觸內容包（C2）**
- 一鍵產出 LINE、IG 私訊、Email、合作備忘錄、FB 貼文
- 全部複製即用

## 完整功能

- 輸入專業、客群、區域、報價，AI 產出客戶生態圈分析
- 5 個最值得開發的合作對象，附開場話術
- 每個對象有 6 個進階深挖選項
- 自動存檔，支援多份地圖管理
- 列印 / 存 PDF

## 給學員的設定步驟

1. 到 console.anthropic.com 註冊帳號
2. API Keys → Create Key
3. 複製 sk-ant- 開頭的 Key
4. 在 Billing 充值最低 5 美金
5. 打開工具，貼上 Key

## 費用估算

- 每張地圖約 NT$1
- 每次深挖約 NT$0.5-1
- 跟 Brian 對話每則約 NT$0.2

## 合規聲明

本工具產出的「找人管道」僅包含公開合法的接觸管道，不會輸出個人手機、私人 email，也不會建議任何違反個資法的行為。
