# Brian's Toolkit

老闆的接案學院（CEO Brian）學員專屬工具集。

從找客戶、寫提案、談價格、到長期合作，每個工具都用 Brian 的「顧問式接案」邏輯設計。

## 目前可用的工具

### 01 異業合作探索器（The Allied Map）
告訴它你的專業與目標客群，AI 幫你畫出客戶生態圈、5 個高價值合作對象、開場話術、找人管道，還有現成的 LINE / IG / Email 接觸內容包。

### 02 高價報價產生器（The Price Architect）
輸入案件條件，AI 用「商業價值」思維幫你產出 3 段式高價報價、開場話術、預想拒絕回應，告別「工時 × 時薪」的窮忙公式。

### 03 客戶異議拆解器（The Objection Decoder）
把客戶的拒絕原話貼進來，AI 拆解他真正的擔心，給你 3 種回應劇本、跟進計畫、漂亮放生策略。

## 給學員的使用說明

**第一步：取得通行碼**
請[加 Brian 的 LINE](https://lin.ee/9Ba3XjY)申請學員資格。

**第二步：設定 Anthropic API Key（一次性）**
1. 到 [console.anthropic.com](https://console.anthropic.com) 註冊帳號
2. API Keys → Create Key
3. 複製 sk-ant- 開頭的 Key
4. 在 Billing 充值最低 5 美金

**第三步：開始使用**
打開首頁 → 輸入通行碼（這台電腦只要驗證一次永久有效）→ 選工具 → 第一次用會請你貼 API Key。
