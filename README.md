# Brian's Toolkit

老闆的接案學院（CEO Brian）學員專屬工具集。

從找客戶、寫提案、談價格、到長期合作，每個工具都用 Brian 的「顧問式接案」邏輯設計。

## 目前可用的工具

### 01 異業合作探索器（The Allied Map）
告訴它你的專業與目標客群，AI 幫你畫出客戶生態圈、5 個高價值合作對象、開場話術、找人管道，還有現成的 LINE / IG / Email 接觸內容包。

### 02 高價報價產生器（規劃中）
### 03 客戶異議拆解器（規劃中）

## 給學員的使用說明

**第一步：取得本期通行碼**
請[加 Brian 的 LINE](https://lin.ee/9Ba3XjY)申請學員資格，會給你本期通行碼。

**第二步：設定 Anthropic API Key（一次性，5 分鐘）**
1. 到 [console.anthropic.com](https://console.anthropic.com) 註冊帳號
2. 左側選單 → API Keys → Create Key
3. 複製 `sk-ant-` 開頭的 Key
4. 在 Billing 充值最低 5 美金（約 NT$160）

**第三步：開始使用**
打開首頁 → 輸入通行碼 → 選工具 → 第一次用會請你貼 API Key，貼完即可使用。

## 費用說明

- 通行碼由 Brian 的接案學院提供（學員專屬）
- AI 費用由你自己付（每張地圖約 NT$1，5 美金可用幾百次）
- API Key 只存在你瀏覽器，不會傳到任何第三方

本工具產出的「找人管道」僅包含公開合法的接觸管道，並會明確警示需謹慎使用的方式（如簡訊開發）。不會輸出個人手機、私人 email，也不會建議任何違反個資法的行為。
